# 演示脚本一 · 商品目录优化(7 轮全链路)

> 数据说明: 场景表 `scn1_categories`(类目)/ `scn1_products`(商品 300)/ `scn1_search_exposures`(搜索曝光 4.5 万)/ `scn1_clicks`(点击)/ `scn1_conversions`(转化)。
> 由 `scripts/seed_data.py` 确定性生成(seed=42),数据截止 2026-09-30,"近 60 天" = 2026-08-02 ~ 09-30。
> 预埋业务真相(种子脚本输出核对表): 大盘点击→下单转化率 **2.5%**;厨房小家电 **1.01%**;其中 200-300 元价格带 **0.55%**;「静音破壁机」关键词点击率 **0.37%** vs 全站平均 **3.39%**;厨房小家电价格/成本比 **1.42** vs 其他类目 **1.15**(溢价约 23%)。
> 演示素材: [竞品价格对照.csv](assets/竞品价格对照.csv)(30 行,厨房小家电本品价格高于竞品 12%-25%)。
> 自动化版: `uv run --project backend python backend/demo_scripts/run_demo_conversation.py --scenario catalog`(无需 API Key)。

每轮演示中,请在右侧「实时任务区」观察: 任务状态流转、当前步骤、工具执行过程、结果文件生成状态。

---

## R1 总览: 目录整体转化表现

**输入**: 帮我看看最近60天商品目录的整体表现,有没有明显的转化问题?

- 预期工具: `db_query`(按类目聚合点击→下单转化率)
- 预期证据: 厨房小家电转化率 1.01%,明显低于大盘 2.5%
- 预期阶段结论: 厨房小家电是转化洼地(影响范围: 该品类全部商品),待补充价格分布与竞品数据
- 展示点: 六部分结果首轮呈现;流式文本 + 工具卡片 + 结果文件生成状态

## R2 追问价格: 为什么转化这么低?

**输入**: 为什么厨房小家电转化这么低?和价格有关吗?

- 预期工具: `db_query`(价格带 × 转化率 + 价格/成本比)
- 预期证据: 200-300 元价格带转化仅 0.55%;加价率 1.42 vs 其他类目 1.15
- 预期阶段结论: 价格是主因——溢价约 23%,主力价格带转化减半
- 展示点: 多轮追问 → 基于上一轮结论深化(结果区「上一轮结果」注入上下文的体现)

## R3 补充证据: 上传竞品价格对照表

**输入**: (先点击附件按钮上传 `docs/demo/assets/竞品价格对照.csv`,观察解析状态 pending→parsing→parsed)我上传了竞品价格对照表,结合附件数据分析溢价情况

- 预期工具: `text_search`(检索已解析附件)
- 预期证据: 附件证据 source_type=attachment——破壁机/电饭煲/空气炸锅价格高于同配置竞品 12%-25%
- 预期阶段结论: 附件印证定价系统性高于竞品
- 展示点: 附件上传/解析状态流转;text_search 命中片段;证据列表 source 多样性(附件 vs 数据库)

## R4 追问曝光: 有没有被埋没的好商品?

**输入**: 搜索曝光效率怎么样?有没有被埋没的好商品?

- 预期工具: `db_query`(关键词点击率排名)
- 预期证据: 「静音破壁机」点击率 0.37%,仅为全站 3.39% 的 1/9(在售破壁机商品名/主图均未含"静音"卖点,搜索相关性差)
- 预期阶段结论: 高需求搜索词被浪费,卖点表达缺失
- 展示点: 证据 confidence=high;漏斗思维(曝光→点击→转化)的第三类证据

## R5 最终报告: 综合输出 + 结果文件

**输入**: 综合起来,给出商品目录优化最终报告

- 预期工具: `result_file`(生成「商品目录优化行动清单.md」)+ `submit_analysis_result`
- 预期阶段结论: 两大归因——定价溢价 23% + 静音卖点缺失;建议 ≥3 条
- 展示点: **结果文件生成状态**;「下载报告文件」「导出 md/html/json」「复制 Markdown」;结果文件重新下载(验收标准 6)

## R6 追问模拟: 调价 10% 影响

**输入**: 刚才说调价10%,如果按这个幅度模拟一下影响?

- 预期工具: `file_write`(写模拟参数)+ `command_exec`(沙箱 Python 模拟,需管理员先在管理端开启 `feature.command_exec` 功能开关——顺带演示功能开关热更新)
- 预期证据: source_type=command,模拟输出"价格-10% → 转化率约 0.69%(+25%)"
- 预期阶段结论: 模拟支撑调价试点
- 展示点: 沙箱命令执行卡片;功能开关开启前后 tool 列表变化(开关关闭时执行被拒)

## R7 归档: 触发上下文摘要压缩

**输入**: 归档这个结论,整理成最终报告

- 预期工具: `submit_analysis_result`(综合四类证据的最终报告)
- 预期阶段结论: 最终归档报告(建议含"试点调价 + 两周复盘"等动作)
- 展示点: 长对话**上下文摘要压缩**(管理端将 `analysis.summary_trigger_msgs` 调低到 8 可更快触发;生产默认 30 条),切换会话重进后可验证压缩后仍能正确延续上下文
