# 演示脚本二 · 客户行为分析(6 轮全链路)

> 数据说明: 场景表 `scn2_customers`(用户 2000)/ `scn2_visit_events`(访问事件约 8 万)/ `scn2_cart_events`(加购事件约 2 万)/ `scn2_order_events`(下单事件)。
> 预埋业务真相(种子脚本输出核对表): 渠道 A 贡献 **39.5%** 访问但访问→下单转化率仅 **1.00%**,B/C 渠道为 **3.57% / 3.44%**;加购用户 **37.9%** 在 3 天窗口内未下单流失;会员复购率 L1 **19.8%** / L2 **34.5%** / L3 **56.7%** / L4 **90.2%**(L3+ 约为 L1 的 3.2 倍)。
> 演示素材: [渠道投放明细.xlsx](assets/渠道投放明细.xlsx)(200 行;渠道 A 投放素材为促销主题,落地页却是新品首发页——素材与落地页错位)。
> 自动化版: `uv run --project backend python backend/demo_scripts/run_demo_conversation.py --scenario behavior`(无需 API Key)。

## R1 总漏斗: 访问→加购→下单

**输入**: 看看最近60天客户行为的总漏斗:访问→加购→下单的转化情况如何?

- 预期工具: `db_query`(三事件表用户数漏斗)
- 预期证据: 访问用户约 2000,加购约半数,加购用户中仍有约 38% 未产生订单
- 预期阶段结论: 加购→下单环节存在明显流失,需定位流失集中的渠道与人群
- 展示点: 六部分结果;漏斗口径在关键指标区呈现

## R2 渠道拆解: 哪个渠道拖后腿?

**输入**: 按渠道拆解一下访问→下单转化率,哪个渠道拖后腿?

- 预期工具: `db_query`(分渠道 visits + 下单用户数)
- 预期证据: 渠道 A 贡献 39.5% 访问但转化率 1.00%,仅为 B/C(3.57%/3.44%)的约 1/3.5
- 预期阶段结论: 渠道 A 是转化洼地——贡献近四成流量、转化垫底
- 展示点: 追问驱动的归因下钻;证据 related_metric 关联到关键指标

## R3 补充证据: 上传渠道投放明细

**输入**: (上传 `docs/demo/assets/渠道投放明细.xlsx`,等待解析)我上传了渠道投放明细表,看看渠道A的投放有什么问题

- 预期工具: `text_search`(附件检索"落地页/素材")
- 预期证据: 渠道 A 素材为促销主题(满减/秒杀),落地页却指向新品首发页——用户预期与页面内容错位
- 预期阶段结论: 渠道 A 转化低是投放执行质量问题(素材-落地页不匹配)
- 展示点: xlsx 解析管线;附件证据与数据库证据互证

## R4 追问流失窗口: 加购后多久流失?

**输入**: 加购后没下单的用户,一般多久就流失了?

- 预期工具: `db_query`(加购用户无订单占比)
- 预期证据: 37.9% 的加购用户在 3 天窗口内未下单即流失,召回窗口极短
- 预期阶段结论: 加购后 3 天是黄金召回窗口
- 展示点: 归因从"谁流失"到"何时流失"的时间维度下钻

## R5 会员分层: 复购率差异

**输入**: 不同会员等级的复购情况怎么样?

- 预期工具: `db_query`(等级 × 复购率)
- 预期证据: L1 复购 19.8%,L3+ 达 56.7%~90.2%,约为 L1 的 3.2 倍
- 预期阶段结论: 会员等级是复购核心杠杆,资源向 L1→L2 晋级倾斜
- 展示点: 第四类归因证据(人群分层)

## R6 最终报告: 综合输出

**输入**: 综合全部发现,给出客户行为分析的最终报告

- 预期工具: `submit_analysis_result`(综合四类证据)
- 预期阶段结论: 三大发现——渠道错位(1.00%)、加购 3 天流失(37.9%)、会员复购杠杆(3.2 倍);建议 ≥4 条(修复落地页、24 小时召回、L1→L2 晋级活动、周会同步)
- 展示点: 结果导出/复制/下载;切换会话后重进验证历史与摘要压缩
